# oarust

`oarust` is the planned [crates.io](https://crates.io/) distribution name for
[OA](https://github.com/realminc/oa), a Rust and Vulkan computing framework.

This initial `0.0.1` package contains documentation only. It does **not**
contain the OA runtime or expose any compute API. Do not add it as a dependency
expecting the examples in the OA repository to work. The current Rust source
and release artifacts are available from the [OA repository](https://github.com/realminc/oa).

The Python distribution is [`oapython`](https://pypi.org/project/oapython/);
it provides the `oa` import package. The Rust and Python distributions have
separate version histories.
