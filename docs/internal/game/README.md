# OA game plans

This directory owns internal product and integration plans for games that use
OA as an external consumer. It does not make game-specific code part of the OA
library and does not override the canonical
[OA Rust architecture](../architecture/oaArchitecture.md) or
[port roadmap](../architecture/roadmap/portRoadmap.md).

- [OA Lunar product and port-integration roadmap](oaLunar.md) — the planned
  interactive Lunar Lander game, reinforcement-learning laboratory, Viewer-first
  rendering path, repository boundary, and parallel-workstream protocol.
- [Android development readiness](androidReadiness.md) — dated workstation,
  toolchain, physical-device, Rust-target, and OARS Vulkan compatibility evidence
  for the first Android slice.
- [moto g06 power stock Vulkan report](reports/lagosStockVulkan.md) — first
  physical-device identity, stock-driver capabilities, and the exact current
  OARS admission failure.
