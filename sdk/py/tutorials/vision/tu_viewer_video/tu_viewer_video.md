# tu_viewer_video — Native GPU video playback (Python)

Play an H.264, H.265, VP9, or AV1 file through the same native Vulkan
Video pipeline the Rust tutorial demonstrates — OA's demuxer, codec
parsers, DPB management, and GPU presentation, with no external codec
library linked.

![Decoded poster frame](../../../../rs/tutorials/vision/tu_viewer_video/asset/poster-frame.png)

*The shared poster frame, produced by the Rust tutorial's `--poster`
mode — OA decode, OA presentation, OA PNG encode.*

## What this tutorial covers

The Python bindings expose the same level-0 viewer surface: one
`oa.ViewerConfig`, one call, a complete player window with timeline,
scrub bar, and pan/zoom navigation.

```python
config = oa.ViewerConfig()
config.mode = oa.ViewerMode.Video
config.loop_media = False
config.title = "OA Viewer · Video"
oa.Viewer.preview(path, config)
```

Everything underneath — container demux, bitstream parsing, Vulkan Video
submission, DPB lease management, on-device YUV→RGBA presentation — is
the same OA Rust engine the native tutorial uses.

## Codec coverage

Identical to the Rust path: H.264 Baseline/Main/High 8-bit, H.265
Main/Main10, VP9 Profile 0/2 (8/10-bit), AV1 Main 8/10-bit, all 4:2:0.
Unsupported profiles fail closed with a capability error.

The full pipeline explanation, qualified matrix, and level-1
`VideoPlayer` walkthrough live in the Rust peer document:
[`tu_viewer_video.rs` tutorial](../../../../rs/tutorials/vision/tu_viewer_video/tu_viewer_video.md).

## Run

```bash
# default fixture (H.264 High)
python3 sdk/py/tutorials/vision/tu_viewer_video/tu_viewer_video.py

# any supported clip
python3 sdk/py/tutorials/vision/tu_viewer_video/tu_viewer_video.py <file.mp4>
```
