# tu_image_grid_classify

Fashion-MNIST classification rendered as a 5×5 prediction grid through `oa::plot::Figure` — the Keras classification tutorial parallel.

## Run

```bash
cargo run -p sdk --release --example tu_image_grid_classify
```
