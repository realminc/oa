# tu_plot_gallery

Nine deterministic diagnostic plots, two themes, one GPU compositor — the same retained `Figure` replays to PNG and to `oa::Viewer`.

## Run

```bash
cargo run -p sdk --release --example tu_plot_gallery
```

The complete runnable implementation is [`tu_plot_gallery.rs`](./tu_plot_gallery.rs).
