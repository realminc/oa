# tu_audio_commands

Speech-command recognition end to end — mel features plus a CNN classifier trained with autograd. Mirrors the TensorFlow "simple audio" tutorial on OA's ML stack.

## Run

```bash
cargo run -p sdk --release --example tu_audio_commands
```

The complete runnable implementation is [`tu_audio_commands.rs`](./tu_audio_commands.rs).
