# OA SDK

Source-companion examples, tutorials, and applications for the OA Rust crate.

## Structure

```
sdk/
├── examples/     # Minimal examples by domain
├── tutorials/    # End-to-end tutorials
└── apps/         # Maintained native tools
```

- ML operations
