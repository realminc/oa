# OA Vision presentation assets

**Status:** Generated tutorial assets

`oa-vision-data-augmentation.png` is generated by the checked C++ tutorial
`sdk/cpp/tutorials/vision/tutorialVisionDataAugmentation.cpp` from
`sdk/asset/image/visionTestPattern320x180.jpg`. The source fixture is an OA-owned
codec and image-operation test pattern.

Regenerate from the repository root:

```bash
cmake --build build/release --target TutorialVisionDataAugmentation
bin/release/tutorial/vision/tutorialVisionDataAugmentation \
  sdk/asset/image/visionTestPattern320x180.jpg \
  sdk/asset/documentation/vision/oa-vision-data-augmentation.png
```

The expected output is a 1200×760 RGBA PNG. Its revision-specific hash is
tracked by the developer-site synchronization snapshot rather than copied into
this prose file.
